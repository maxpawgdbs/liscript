# LiScript

LiScript — интерпретатор Lisp-подобного языка, написанный на Python. В проекте есть интерактивная консоль (REPL), стандартная библиотека на самом LiScript и примеры программ.

Язык поддерживает списки и S-выражения, рекурсию, замыкания, частичное применение функций, лексическую и динамическую области видимости, изменяемые переменные и генерацию кода.

## Запуск

Нужен Python 3. Внешних зависимостей нет; примеры ниже проверены на Python 3.13.3.

Из корня проекта выполните:

```sh
python main.py
```

При запуске автоматически загружается [стандартная библиотека](stdlib/liscript.clj), после чего появляется приглашение `>>`:

```text
LiScript dev version by november 2026
>> (+ 1 2 3)
6
>> (defn square (x) (* x x))
()
>> (square 7)
49
>> (map square (range 1 5))
(1 4 9 16 25)
```

В REPL вводите выражение целиком на одной строке. Можно записать несколько завершённых выражений в одной строке — результат каждого будет напечатан отдельно. Для выхода нажмите `Ctrl+C`.

## Загрузка программ

Команда `:l` читает файл в UTF-8 и выполняет его в текущем окружении:

```text
>> :l programs/account.clj
()
>> (def wallet (account 100))
()
>> ((wallet 'add) 25)
125
>> ((wallet 'sub) 40)
85
```

В файлах можно писать многострочные выражения. После выполнения файла выводится результат последнего выражения, а вызовы `print` печатают данные по мере выполнения.

Пути считаются от текущего рабочего каталога; команда загрузки не поддерживает пробелы в пути. Запускать интерпретатор нужно из корня проекта, чтобы он нашёл стандартную библиотеку. Передача имени программы аргументом `main.py` не предусмотрена.

В каталоге [programs](programs) находятся примеры:

| Файл | Что демонстрирует |
| --- | --- |
| [factorial.clj](programs/factorial.clj) | Ввод числа, вычисление факториала через `eval` и изменение переменных |
| [account.clj](programs/account.clj) | Замыкания с состоянием: счёт и словарь |
| [set-multiset.clj](programs/set-multiset.clj) | Множество и мультимножество позиций, генерация имён переменных |

| [while-knight.clj](programs/while-knight.clj) | Функция поиска маршрута коня с циклами и учётом посещений |

Некоторые файлы только определяют функции. Например, после загрузки `while-knight.clj` функцию `knight` нужно вызвать отдельно.

## Синтаксис и значения

Вызов записывается как `(функция аргумент ...)`. Числа, строки и логические значения вычисляются сами в себя. Символы обозначают имена, а списки без цитирования интерпретируются как вызовы.

```clojure
42                  ; целое число
3.14                ; число с плавающей точкой
"hello"             ; строка
true                ; логическое значение
'hello              ; символ
'(1 2 3)            ; список без вычисления элементов
(quote (1 2 3))     ; полная форма цитирования
()                  ; пустой список
nil                 ; имя пустого списка из стандартной библиотеки
```

Комментарий начинается с `;` и продолжается до конца строки. Запятые, как и пробелы, разделяют элементы.

| Операции | Назначение |
| --- | --- |
| `+`, `-`, `*`, `/`, `%` | Арифметика |
| `++` | Объединение строковых представлений значений |
| `=`, `>`, `<`, `>=`, `<=` | Сравнения; можно передать несколько аргументов |
| `cons`, `car`, `cdr` | Добавление в начало списка, первый элемент и хвост |
| `typeof`, `symbol` | Имя типа и создание символа |
| `print`, `read` | Вывод и чтение одного выражения |
| `def`, `set!`, `do` | Определение, изменение и последовательное выполнение выражений |
| `cond`, `while-core` | Ветвление и встроенный цикл |
| `lambda`, `dambda` | Функции с лексической и динамической областями видимости |
| `quote`, `eval`, `eval-in` | Цитирование, вычисление кода и вычисление в окружении замыкания |
| `racro`, `defmacro`, `macroexpand` | Подстановка кода и раскрытие макросов |
| `error` | Создание ошибки с сообщением |

У арифметики есть особенности: `(/ 7 2)` возвращает `3`, а `(/ 7 2.0)` — `3.5`. Между целыми числами используется деление с округлением вниз. Операторы сворачивают аргументы слева направо; `(- 5)` возвращает `5`. Равенство учитывает тип: `(= 1 1.0)` возвращает `false`.

## Переменные, условия и циклы

`def` создаёт привязку в текущем окружении, `set!` меняет существующую. Обе формы допускают несколько пар «имя — значение».

```clojure
(def x 10 y 20)
(set! x (+ x y))

(cond
  (> x 20) "large"
  (= x 20) "equal"
  "small")
; => "large"
```

В `cond` идут пары «условие — результат» и необязательное последнее выражение для случая, когда ни одно условие не выполнено. Условия должны возвращать `true` или `false`.

`do` выполняет выражения по очереди и возвращает результат последнего. Формы `while`, `when`, `+=`, `-=`, `and`, `or` и `not` определены в стандартной библиотеке:

```clojure
(def n 0)
(while (< n 3)
  (+= n 1))
n
; => 3
```

## Функции

`lambda` принимает список параметров и одно выражение тела. `defn` из стандартной библиотеки позволяет дать функции имя и записать несколько выражений тела; результатом будет последнее.

```clojure
(defn factorial (n)
  (cond
    (<= n 1) 1
    (* n (factorial (- n 1)))))

(factorial 5)
; => 120
```

Если функции `lambda` передать меньше аргументов, она вернёт функцию с оставшимися параметрами. Дополнительные аргументы доступны в списке `rest-args`:

```clojure
(defn add (a b) (+ a b))
(def add-ten (add 10))
(add-ten 5)
; => 15

(defn collect (first) (cons first rest-args))
(collect 1 2 3)
; => (1 2 3)
```

Функции `lambda` сохраняют окружение, в котором созданы. `dambda` ищет свободные имена в окружении вызова; частичное применение для неё не реализовано.

## Списки и стандартная библиотека

```clojure
(car '(10 20 30))                              ; => 10
(cdr '(10 20 30))                              ; => (20 30)
(cons 0 '(1 2 3))                              ; => (0 1 2 3)
(range 1 5)                                   ; => (1 2 3 4 5)
(map (lambda (x) (* x x)) (range 1 5))          ; => (1 4 9 16 25)
(filter (lambda (x) (= (% x 2) 0)) (range 1 6)) ; => (2 4 6)
(reduce + 0 (range 1 5))                       ; => 15
(sort '(3 1 2))                               ; => (1 2 3)
```

В отличие от Python, `range` включает обе границы.

Основные функции из [stdlib/liscript.clj](stdlib/liscript.clj):

| Группа | Функции |
| --- | --- |
| Проверки | `nil?`, `list?`, `symbol?`, `contains?`, `all`, `any` |
| Создание и преобразование списков | `list`, `range`, `init`, `repeat`, `append`, `reverse`, `take`, `drop` |
| Обработка списков | `map`, `filter`, `reduce`, `foldl`, `foldr`, `deep-map`, `mapcat`, `zip-with` |
| Другие операции со списками | `length`, `list-ref`, `intersperse`, `distinct`, `sort`, `merge-sort` |
| Функции высшего порядка | `apply`, `iter`, `n-times`, `fix` |
| Математика | `inc`, `gcd`, `fib`, `is-prime`, `prime-factors`, `fast-pow` |

## Код как данные и макросы

Цитирование сохраняет выражение как данные, а `eval` вычисляет его:

```clojure
(eval '(+ 2 3))
; => 5
```

`racro` подставляет переданные выражения в тело без предварительного вычисления аргументов, затем выполняет результат в окружении вызова. Удобная форма определения — `defracro` из стандартной библиотеки:

```clojure
(defracro unless (condition body)
  (cond condition nil body))

(unless false (+ 2 3))
; => 5
```

Также реализованы `defmacro` и `macroexpand`. Автоматическое раскрытие макросов в `eval_text` сейчас отключено, поэтому макросы из `defmacro` требуют явного вызова `macroexpand`. Стандартная библиотека использует `racro` и `defracro`.

## Особенности текущей реализации

- Файлы LiScript используют расширение `.clj`, но выполняются этим интерпретатором; совместимость с Clojure не предполагается.
- По умолчанию в `settings.py` задано `immutable_mode=False`: привязки можно переопределять и изменять. Флаг `True` включает проверки в методах окружения `define` и `set`.
- Имя без привязки возвращается как символ. Попытка изменить отсутствующую переменную через `set!` вызывает ошибку.
- Многострочный ввод в REPL и экранирование кавычек внутри строк не реализованы.
- В репозитории нет отдельного набора автоматических тестов.
